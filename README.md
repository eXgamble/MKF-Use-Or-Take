# MKF - Use Or Take

Items, the [Modifier Key Framework](https://github.com/eXgamble/Modifier-Key-Framework) way.
Activating an item takes it, as always. Hold the modifier key to use it right away:

| Item | Modifier key | Second button (X / R) |
|---|---|---|
| Weapons | Equip | Equip and Draw |
| Armor, torches, arrows and bolts, scrolls | Equip | |
| Potions, and drinks like ale, mead and wine | Drink | |
| Food and ingredients | Eat | |
| Poisons, while you hold a weapon | Apply | |

- Owned items show their label in red: using them is stealing, with the usual bounty if you're seen.
- No plugin, no script: one rule file and a translation file.

Replaces po3's Use Or Take: don't use both.

## Requirements

- Modifier Key Framework 1.8.0 or newer
